# Native solver regression data

`region-pole-degree12.txt` is an exact denominator factor generated by this
library for the all-soft boundary family of the first original-paper target,
at epsilon = 1/2700, with all-line auxiliary-mass placement and RustRed depth 3.
It exposed the dependence of numerical root convergence on coefficient scale.
It is not an upstream reference value or solver boundary datum.

A smaller Symbolica-only reproduction using `10^40 * (x^3 - 2)` is in
[`repros/symbolica-root-scaling`](../../repros/symbolica-root-scaling/README.md).
It retains the historical 3.0.0 output and now checks successful convergence
with the fixed upstream `main` revision.

# Obsolete numerical cache snapshot

`residual-alias-cache-v5.bin` is an intentionally obsolete physical-boundary
snapshot produced by the archived e733 RustFlow library. Its public epsilon
transport returned the incorrect coefficient zero for a polynomial counterexample
whose exact coefficient is −999, then marked the two agreeing profiles as verified.
The fixture must be rejected before any boundary values are admitted; it is never
a usable scientific boundary.

The mathematical counterexample and original reproduction are recorded in
[the residual-alias report](../../reports/validation/2026-10-05-residual-alias-counterexample.json).
The snapshot was generated by that same public transport, saved with the native
version-5 binary cache writer, reloaded, and used for an exact-coordinate hit by
the old binary. The post-fix loader must reject its implementation fingerprint.
