# Reference provenance

All upstream fixtures come from AMFlow 2.0 commit
`26005517a288086c4cb4d1b26d829691bc088485` at
https://gitlab.com/multiloop-pku/amflow.

- `two_loop_input.wl`: `examples/automatic_vs_manual/run.wl`.
- `two_loop_blade_auto.wl`: `examples/automatic_vs_manual/backup/blade_auto`.
- `LICENSE.md`: upstream MIT license, retained verbatim.

The input requests four numerator-rank-three two-loop integrals through epsilon
power zero at s=30, t=-10/3, m²=1. `benchmarks::paper_two_loop` reproduces the
family and target order using exact rational input.

Mathematica backtick precision annotations in the result file are significant.
Printed mantissas contain more digits than their recorded precision supports.
Component precision is sometimes below 20 digits. A comparison must use each
component's own recorded precision and must separately establish 20-digit
stability by increasing working precision, series order, and epsilon samples.
Passing a comparison at the fixture's precision alone is not a 20-digit
validation of the entire result.

`two_loop.json` is generated by `scripts/convert_reference.py`, which accepts only
the numeric grammar used in this fixture, preserves the original component
precision strings, and records the source SHA-256. The acceptance executable
requires both independent 20-digit stability and comparison at the reference's
recorded precision.
