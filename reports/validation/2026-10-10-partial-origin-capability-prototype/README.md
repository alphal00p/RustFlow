# Isolated finite-positive-eta partial-origin prototype

The isolated prototype passes **10 focused tests**. It constructs an immutable, privately populated capability for rational massless physical rows with one or two unrestricted virtual coordinates. It uses the actual prepared occupied family, native HEPKit full off-null Symanzik polynomials, every positive virtual support, and complete max/nonparallel charts. It authorizes a finite-positive-eta source/origin theorem only. It is not integrated into production and is **not production-ready admission**: cancellation, internal CAS work accounting, and consumer condition/label enforcement remain open implementation gates.

`source/src/finite_density/partial_origin.rs` is the final source copy. SHA256: `9fecca0a42c8d9486bd4334384b9271fc90a789482ced0613fc7bb783695028c`. `source-binding.json`, `build-05.json`, `final-gates.json`, and `final-evidence/` bind source, copied VI root/native libraries, executable, exact test results and retained proof data. Compilation used standalone rustc, not Cargo; no production source or shared target was written. Earlier failed compiles and successful earlier gates are retained under distinct names. There is no numerical amplitude or closure-performance claim.

## Implemented authority and checks

* The constructor binds complete physical/factor/role/target/routing data, source options and exact auxiliary placement. It reconstructs and compares the family rather than accepting an unrelated otherwise valid family. Original rational row and inverse-routing sizes, input text, loop/row counts and geometry terms are checked before reconstruction.
* An exact common affine virtual translation removes compact momentum from every unshifted physical row. Physical squared-momentum identities are replayed; no shifted-only rank inference is used. The complete positive virtual support set is retained, including rank-deficient and deleted-line supports.
* Full native U/F is reconstructed with independent shell diagonal invariants, pair invariants, virtual masses and the actual eta subset. Exact linearity, all signed diagonal coefficients, nonnegative pair coefficients, U-alpha mass coefficients, and the auxiliary coefficient are checked. Native U agrees with the exact Gaussian determinant. A conservative rational Schur bound is retained.
* Each full-rank support retains all max-parameter charts. For rank two, each primary/nonparallel pivot chart verifies U=x*U0, a strictly positive constant lower bound for U0, polynomial mean/V cofactors divisible by x, and the complete rational chart map/Jacobian. This is a complete bounded enumeration, not a search for a favorable chart.
* The private theorem version is universal but pointwise: each finite admitted integer label has a computable high-D neighborhood. Explicit audits count actual polynomial momentum degree R, positive virtual powers P, and cut/upper/lower jets J. For rank two, N Taylor terms mean degrees 0 through N-1. The strict remaining-power witness counts J once. Role and storage checks precede even cut-vanishing classification.
* Lower-contact zero boxes use that universal finite-label theorem, not an initial finite target list. Exact positive-support boxes for free virtual polynomial directions and independently regulated vacuum limits are separate. A full-rank support with a shifted positive virtual denominator and V=0 is explicitly **not** a finite-eta zero.

The proof hypotheses and analytic-index/Taylor prescription are documented in the separately frozen `../2026-10-10-rank-two-partial-origin-design/`. The initial joint Gaussian convergence domain permits independent analytic propagator indices; a D-only bare convergence strip for arbitrary polynomial numerators is not assumed. The counterterm prescription is fixed by meromorphic continuation of that family.

## Test scope

The actual three-loop graph fixtures cover singleton cut [3] with eta slot [0] and double cut [0,3] with eta slots [1,2] and [2,4]. Their 16, 4 and 4 supports are reconstructed and replayed. The negative suite covers incomplete/tampered native support/chart evidence, wrong placement/family/options, physical mass, invalid occupation, reciprocal completion, storage tails, failed channel sign and exhausted explicit budgets. Raised cut/upper/lower jets and negative polynomial powers have explicit finite witnesses; integer overflow fails.

The off-null test uses exact future square-root pole data (omega,gamma,r)=(5,3,4) and (13,5,12), so qi^2=-i*epsilon_i with independent same-sign native line-mass regulators. It verifies the reverse-Cauchy identity and physical-channel lower bound, then evaluates every retained full native polynomial on closed binary parameter faces and three angles: **117 exact face/angle checks**, including **54 S=0 common-phase checks**. At fixed positive eta and T, the regulator remains inside the Fermi pole strip; no arbitrary complex null scaling is claimed. Exact polynomial replay, together with the algebraic inequality, is the authority; the rational sample tests are additional regression checks.

A fresh 52-row legacy source context is generated through the existing formal source factory with the actual partial placement. All source rows, guards, coefficient maps and nonzero conditions remain unchanged. The context receives the new origin identity and 11 typed zero boxes; a zero-rule program roundtrips against the exact context and rejects the original foreign context. No historical rule is imported and no source rule is silently added. The test demonstrates source-context binding, not full source-factory/flow integration or reduction closure.

## Deliberate limits and required consumers

1. **Resources:** explicit limits bound input text/rational size, rows/loops, retained monomials, complete supports/charts and adapter event counts. They do not bound work internal to Atom expansion, cancellation, rational rref, or native HEPKit. Some output-size checks necessarily occur after those operations. There is no RunContext/cancellation integration. Before production, thread the existing run/cancellation owner through construction and replay, add appropriate CAS preflights/limits, and test cancellation/exhaustion. Do not describe the current operation counter as a bound on CAS work.
2. **Conditions:** the capability binds the exact input/family and preserves original source conditions. It does not take ownership of pre-cancellation raw target coefficient poles. The future preparation/evaluation consumer must collect and retain those conditions before any algebraic cancellation or zero classification, check them at each epsilon sample, and preserve all reduction conditions. A cut-vanishing or vacuum-zero classification must not erase an undefined original coefficient. No new raw-target-condition acceptance test is claimed here.
3. **Universal schema versus applications:** zero boxes are justified by the universal finite-label theorem version. Every actual source application, candidate, target and final basis label must still pass the role-aware finite-label audit (including all shifted terms and tail checks), with its bounds/conditions recorded. The current standalone tests exercise this API; no production scheduler enforces it yet.
4. **Source API:** a separately sealed source-origin interface is needed to use this token in the existing factory. It must bind placement, options, theorem, complete proof and zero boxes. The prototype uses `free_virtual_zero_sectors` to opt into both free-direction and regulated-vacuum support boxes; production must deliberately choose/document whether to preserve that name or separate the latter option. Existing all-mass defaults and identities are unchanged.
5. **Scope:** initial auxiliary coefficients are exactly one. Purecompact physical denominators are conservatively restricted to shifted equal-and-opposite future differences c(qi-qj); no arbitrary timelike or unshifted compact rational factor is admitted. Inverse completions and massive physical lines reject.
6. **Separate capabilities:** this token supplies neither SingletonGerm/raw-Ward authority, an eta-to-zero endpoint owner, nor a large-eta boundary owner. Those consumers require separate proofs/replay. It does not bypass native target/derivative closure and cannot manufacture masters. No partial-placement physical flow is enabled by this report.

For a rebuild, restore the report source files to the recorded isolated directory, preserve the fixture include path or update it with an explicit new source hash, and use `source/build.py` with the exact recorded libraries. `build-05.json` contains all rustc/linker/native-library arguments. The large executable/rlibs remain in /tmp; immutable hashes and build evidence are retained here instead of duplicating them into git.
