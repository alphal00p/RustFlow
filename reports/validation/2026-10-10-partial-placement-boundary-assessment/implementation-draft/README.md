This draft certifies an ordinary unrestricted virtual factor after the existing region projection. It does not admit a partial auxiliary-mass placement, change the occupied integration measure, classify an entire occupied family as scaleless, or call a numerical zero evaluator. The only proposed production edits are a private child module declaration and the new owner/tests; the certificate is not yet called from evaluation.

For positive coordinate-dependent denominator factors, the owner extracts exact rational rank-one momentum rows. Compact and original external directions form B, unrestricted virtual directions form A. If A has a null direction, it records that polynomial unrestricted direction. Otherwise it solves A*T=B exactly, requires every residual mass to vanish, performs the unit-Jacobian common affine translation on every scalar coordinate and the complete numerator, and checks the transformed denominators contain only virtual Gram products. Nonpositive factors remain numerator polynomials. No propagator is added to positive support by this classification; ordinary to_integrals may add only zero/nonpositive completion slots as usual.

The original denominator syntax is checked before whole-expression cancellation. Any raw compact-coordinate pole, including a removable compact pole, is refused. The remaining numerator must be polynomial in all region coordinates. The translated expression is passed to existing native exact to_integrals, and every resulting ordinary term must receive an actual RustRed Analyzer::ProvedZero certificate. The owner retains that certificate, its exact family and label, reverse-mapped conditions and original parameter denominator conditions. Conditions involving compact integration coordinates are refused, not assumed pointwise. This prevents a native ordinary proof from silently imposing a missing compact-domain restriction.

Distribution validation precedes every certificate path. Invalid H indices or inconsistent loop maps fail. C<=0 returns None so the required-cut owner retains its separate zero semantics. The certificate binds the full RegionFactorSpace, affine map, source loop indices, original/transformed expressions and all native proof objects. A future evaluator must check parameter conditions with exact substitutions before returning zero, retain the incoming reduction conditions, and bind a sealed placement-specific common high-D origin/endpoint proof. The current all-mass proof cannot supply that permission. Source closure alone does not discharge the remaining endpoint or boundary matching obligations.

The five unexecuted tests cover exact numerator translation with retained parameter poles; incompatible shifts, residual masses, compact denominators and removable compact poles; an unrestricted rank-deficient direction with a massive denominator in the other direction; invalid distribution/required-cut semantics; and actual regions generated by shared enumerate_compact/expand_region/projected_factor_region for all three proposed masks through order two. The actual-region fixture includes every original requested label and the two natively closed singleton labels bound in closed-basis-fixture-binding.json. No proof or value is imported from the closure artifact.

Rustfmt and git apply --check pass. The Rust code has not been typechecked or run. All root sources remain unchanged.
