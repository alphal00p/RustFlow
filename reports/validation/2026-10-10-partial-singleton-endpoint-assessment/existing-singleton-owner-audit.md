This read-only audit concerns the existing all-uncut `MasslessFlowEvidence` implementation, separately from the new partial-placement proposal. It does not install an endpoint-zero owner or change assembly dispatch.

`MasslessFlowEvidence::new` validates the exact input/family signature, all physical masses zero, positive chemical magnitudes, polynomial completion policy, and the complete all-uncut shifted inventory through common-channel evidence. The private `SingletonGerm` variant additionally requires exactly one occupied loop, at least one virtual loop, full virtual rank and no external-only uncut factor. A reported string such as `scope()` is descriptive; a future endpoint-only entrypoint must match the sealed enum variant itself. Other admitted variants, including two-cut rank-one blocks, are not authority for a singleton endpoint zero.

`validate_labels` checks arity, completion signs and occupation signs before any zero classification. Every surviving finite full-rank singleton label receives the sufficient inequality h*Re(D)/2-P-J>0, with P counting all positive uncut powers and J the required-cut mass jets plus upper-surface jets. The separate compact-origin inequality is Re(D)-2-2J>0. Missing required cuts and lower-contact labels retain their existing distinct proofs. Rank-deficient positive virtual supports have an unrestricted polynomial virtual direction; they are not confused with merely zero kinematic Symanzik data. Finite polynomial numerators add nonnegative Gaussian covariance powers and polynomial external factors, so the worst endpoint exponent is still the stated bound. Each finite collection of labels has a common sufficiently high nonpole dimension neighborhood; no uniform dimension over an unbounded integer lattice is claimed.

This supports an additive physical-endpoint zero theorem in the already proved class. It does not make the finite-eta family zero. Raised cuts must be represented by the fixed-original mass jets before the null restriction; dropping q^2 C_n contacts for n>1 would be invalid. A theorem evaluation report must explicitly say it used endpoint evidence, not claim native closure, boundary evaluation or transport. The existing completed cut0 AMF calculation remains an independent control.

Coefficient-domain handling remains a separate obligation. A new shortcut owner must collect raw original target numerator/coefficient denominator conditions before cancellation, physical mass substitution and removal of missing-cut terms, then check them at every epsilon sample. Conditions from an auxiliary finite-eta Gamma representation are not automatically new original physical domains. Conversely, zero times an undefined original coefficient is not a permitted target. The old unmerged `/tmp/massless_endpoint_zero.rs` draft attempts that raw-condition collection; it is not a compiled public API or evidence of a passed numerical shortcut test.

Existing unit fixtures in `massless_endpoint.rs` exercise C2/H3 with J=3, missing required cuts, polynomial virtual supports, lower-origin jets, inverse-completion rejection, changed placement rejection, E7 generated labels, routing shears, and external-only factors. This audit did not rerun them. Before an endpoint-only owner is promoted, add a focused gate covering: actual raised and medium-polynomial targets against existing AMF; explicit upper H1/H3 labels; retained poles in canceled or cut-vanishing targets; massive physical-line rejection even when the occupied mass is zero; inverse-energy rejection even when a required cut is absent; typed rejection of a valid two-cut block permit; invalid negative H indices; changed family/placement/options/cache identity; and a finite-eta nonzero control preventing accidental installation as a native source zero. These are required future tests, not current pass claims.
