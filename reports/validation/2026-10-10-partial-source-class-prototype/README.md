# Private partial-source class checker — isolated validation

The isolated checker passes **9 tests** against hash-verified copied RustFlow/RustRed libraries. It checks the actual singleton cut `[3]`, shift `[0]`, and double cut `[0,3]`, shifts `[1,2]` and `[2,4]`. No production source or shared build output was changed. `summary.json` gives the exact source/face counts and test resources. The unapplied `source-class.patch` adds the private module and its tests; registering the module and supplying the typed partial bundle remain integration work.

## Authority and coverage

The admitted class has polynomial completion indices <=0, occupation indices >=0, and fixed-zero storage tails. Physical ordinary indices are unrestricted; a nonpositive required cut is an exact zero only after every other tuple component has been validated. Each complete source row is checked before native discovery or cut-zero projection. Equal images are combined exactly, all fixed guard coordinates are specialized, and every bounded violating integer face must have identically zero coefficient. A boundary coefficient may vanish even where its formal image exceeds the completion box. Conditions are retained unchanged, including conditions on canceled terms.

This is a class-preservation certificate, not a proof that a physical IBP identity is valid. The typed partial bundle must first validate exact input/family/placement/options and the universal pointwise finite-label continuation theorem. The certificate then binds those supplied identities, role/layout/admitted box, and the complete native source-only program encoding (rows, maps, guards, conditions and zero domains). It imports no rules. Native guarded seed/recenter/replay preserves the certified class; no new reducer or native observer is added. No single dimension for an unbounded symbolic ray, exhaustive applied-label trace, endpoint theorem, or numerical result is claimed.

The low-level API is `certify_source_image_class(context, admitted, binding, budget, run)`. The immutable nongeneric certificate exposes `report()` and `validate_context(context, admitted, binding, run)`. `SourceImageBinding` is crate-private and is constructed by the typed bundle, not the flow caller. The intended flow consumer calls `bundle.validate_sources(...)`, preserving ownership of the physical authority.

## Exact scope of the actual-source test

The pinned public factory emits the unchanged formal polynomial source rows. The test copies those rows and retained conditions exactly into a fresh native context, attaches the independently validated frozen origin capability's zero domains, and binds its full origin identity. It does not invoke a not-yet-integrated public partial-flow factory. The options enable the existing PolynomialClosure presentation and bound free-virtual-zero policy; the public row generator is called with its private-zero feature disabled, then the exact origin owner supplies the zero boxes. This changes the context's origin binding and zeros, not its source identities. All three fixtures are regenerated from the original input rather than loaded from an old reduction.

## Tests and limits

Synthetic controls check ordinary and shifted boundary annihilation, two violating faces, specialization of a different fixed coordinate, invalid H/completion/tails despite an absent cut, whole-row cancellation, a nonzero invalid intermediate, raw source conditions, changed physical/context bindings, conservative fixed-pattern rejection, inverse-completion rejection, cancellation and structural budgets. Native construction itself rejects fixed raw powers on a free source coordinate; the test records that upstream rejection rather than bypassing it. Final-basis/derivative and physical endpoint/boundary audits remain separate mandatory consumers.

Budgets cover arity, rows, aggregate raw terms/conditions, polynomial term count and total degree, coefficient bit size, bounded integer-face count/magnitude, binding fields/bytes and encoded source bytes. Coefficient-size checks apply to inputs and retained merged/fixed-specialized/face outputs. Source/domain traversal and CAS calls remain finite; cancellation is checked between operations. These checks do **not** bound internal CAS allocation, normalization scratch, encoder scratch, or single-operation time. Numeric/fixed raw source patterns and unbounded violating sets are conservatively unsupported. Nonzero-condition logic is not used to excuse a nonzero invalid image.
