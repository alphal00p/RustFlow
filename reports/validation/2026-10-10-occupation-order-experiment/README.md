# Occupation-degree ordering experiment

This isolated experiment does not change the production RustRed policy. It asks
whether prioritizing total occupation degree reduces growth of surface terms in
the three-loop raised-numerator reduction. The baseline point-search evidence
and a replayed single-source orientation witness are retained in
[`three-loop-point-active-pilot`](../2026-10-09-finite-density-native-assembly/three-loop-point-active-pilot).

The experimental comparator places **only total occupation degree** before the
existing physical key. At equal occupation degree it retains every physical
priority, then the existing occupation coordinate tie break. This differs from
the separately proposed, unapplied total-degree-plus-lexicographic prefix patch
in that baseline directory.

All admitted occupation indices are nonnegative. A strict decrease of their
sum can occur only finitely often from a numerical target; at fixed sum the
existing physical ordering supplies the next priority. Symbolic occupation
differences cancel their common base. Fresh source replay still checks the
nonnegative domain, ordinary sector stability, exact row identity, every source
condition and strict descent using the same comparator. These facts motivate
the experiment; neither an orientation witness nor a bounded pilot establishes
complete reduction coverage.

`experimental.patch` applies only to a separate copy under `/tmp`. It also uses
a distinct experimental persistence tag. Historical programs are read only to
recover the original source corpus and integral definitions; their old rules
must not be imported into experimental discovery. The production library and
experimental library use the same six resolved dependency artifacts, recorded
in `build-binding.json`. The experimental native library is optimized, without
debug information. Diagnostic wrapper timing is not production performance.

The isolated native build passed in 184.43 seconds with peak child RSS
5,871,336 KiB. This measurement **includes native compilation** and excludes Nix
startup and Python preparation/hashing. The generic scope string emitted by
the shared resource wrapper incorrectly says compilation is excluded; the
actual command and numerical measurements are retained, with the correction
recorded in `build-binding.json`.

No integral values, oracle constants, numerical boundaries or hand-selected
masters enter this experiment. A useful outcome would require native replay of
all original targets and their complete differential system in an automatically
discovered finite spanning basis, followed by separate boundary and numerical
validation. There is no three-loop or four-loop numerical acceptance here.

## Completed bounded outcomes

All three arms remain unclosed. No comparator change was made in production.
The third arm inserts occupation degree after denominator count, sector and
required-cut degree, but before ordinary absolute and numerator degree.

| Native order | Completed active frontiers | Final status | Prebuilt wall time |
| --- | --- | --- | --- |
| Production v2 zero-projection baseline | 54 → 203 → 633 → 1025 | Frontier cap 1024 | 250.672 s |
| Occupation degree before physical order | 54 → 341 → 1000 | Timeout during next round | 300.014 s |
| Cut degree before occupation degree | 54 → 207 → 598 → 1025 | Frontier cap 1024 | 258.480 s |

These are matched native-source discovery pilots with depth 3, one ray and one
point-fallback domain per requested label, at most 16 rounds, 4096 cumulative
requests, 65536 rules, 8192 direct-zero row attempts per round and a 300-second
process limit. Diagnostic wrappers are unoptimized; library dependencies are
optimized. Compilation is excluded from the pilot times. The original outputs
and each actual derivative are combined exactly; every new basis label is
searched before differentiation, and successful closure would require a final
native target-and-derivative audit. Neither a frontier cap nor a timeout supplies
that audit. The timeout has no final result; only its three completed rounds are
reported. The two explicit frontier failures return process status zero because
the diagnostic completed successfully, not because the integral system closed.

The narrower third order reduces the last complete raised-target remainder from
1506 to 1381 labels; it still exceeds the same bound. The first experiment removes
upper surfaces at the expense of more raised-cut labels. These observations do
not establish a useful finite basis or justify an ordering-policy change.

[`pilot-three-arm-summary.json`](pilot-three-arm-summary.json) preserves counts,
conditions, exact commands and source/checkpoint hashes. The earlier two-arm
summary remains unchanged as historical evidence. Both experimental comparator
invariant gates pass 839808 symbolic/common-base comparisons, 729000 transitivity
triples, ordinary-order invariance and role/zero checks. All three full-source
witness searches select the same multiplication recurrence, so that witness is
nondiscriminating. In the separately declared single-original-Euler-source
control, both experimental orders discover and replay the reversed surface-to-
bulk identity, whereas the baseline reports no rule. This is a restricted source
proof, not full-corpus closure. See
[`witness-three-arm-summary.json`](witness-three-arm-summary.json).

Each experimental program round-trips under its own native library and is
rejected by the production proof schema; production programs are rejected by
both experimental schemas. No historical rule proof is imported into discovery.
The library/source/dependency bindings remain separate for all three arms.

## Archived artifacts

Verbose checkpoints, witness programs and logs are losslessly gzip-compressed.
`archives.json` maps every original path and SHA256 to the compressed path and
SHA256. Every archive was decompressed and compared byte-for-byte before the raw
file was removed. Existing source bindings deliberately retain the original raw
hashes; resolve an absent path through that map, or restore it with
`gzip -dk PATH.gz`. Rust/Python diagnostic sources, input/source bindings,
resource measurements and concise summaries stay uncompressed. `manifest.json`
records the final stored file hashes. No active probe process remains.
