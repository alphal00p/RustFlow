# Smallest partial fixed-shell integration

The smallest useful numerical promotion is the generic one-virtual-loop, two-compact-loop subclass of the reviewed partial capabilities. This includes either tested double placement after its exact affine-routing witness. It avoids a new connected two-loop hard boundary problem while exercising a nonzero occupied contribution. It is a structural restriction, not graph-name or mask dispatch. The rank-two singleton remains a valuable independent flow/boundary control; the current physical-singleton-zero owner means full assembly need not depend on that expensive flow.

No production source or build was changed for this assessment. The endpoint prototype passed 18 tests and its independent review checked 36 exact bound records. The later virtual-soft certificate passed 11 isolated tests and supplied 51 actual-region native ordinary-zero certificates; its revised private API and inherited-guard handoff supersede the older uncompiled draft. These facts do not imply numerical partial-flow acceptance. In particular both longer partial-double closure controls timed out at 1200 seconds, at frontiers 937 and 1008. There is no saved closed double basis to treat as a known boundary.

## Boundary hard contributions

For h=1, any surviving all-virtual-hard factor is a one-loop vacuum expression with quadratic leading denominators at masses 0 or the unit eta mass. Nonunit rational momentum coefficients merely change the exact rational mass and normalization after scale extraction. Existing `integrand::to_integrals` performs exact partial fractions/completion and retains numerator insertions. `RecursiveBoundary` with `TadpolesOnly` and `bubble_subloops=false` owns each resulting ordinary integral. A massless hard term can be zero only through its ordinary owner, not because the occupied target looks scaleless. The shifted purecompact transfer contributes its explicit eta expansion and polynomial compact coefficient; it must not be dropped from P0 or the region exponent.

Every non-all-hard term must be checked as actually generated. Under the affine-placement criterion, the retained undeformed soft rows have a simultaneous compact-removing translation inherited from the virtual routing. The per-term certificate verifies this algebra and supplies a native ordinary zero proof. If a projected soft term retains a compact rational denominator, incompatible shift, residual mass or coordinate-dependent guard, reject it; do not fall back to blanket zero. This gives a deliberately narrow boundary class without a new general rational weighted-soft solver.

For h=2, the all-hard singleton can contain both K^2 and K^2-1. The existing converter's scalar and raised/numerator duplicate-factor checks already reconstruct these exactly into massless vacuum and one-mass hard families. The separate one-mass connected hard111 check passed three profiles at D=12/5 using the generic single-mass peel and recursive AMF. That is evidence for one surviving period, not every raised hard factor or every coefficient needed by a new Frobenius order. Before h=2 live admission, evaluate all actually generated hard children of the two saved closed singleton masters through the same owner and test joint boundary matching under precision/order/start-point refinement. The old equal-mass check cannot stand in for these one-mass children.

The mathematical infinity argument must retain the existing generic large-mass expansion on its regulated analytic family and apply the compact distribution jets to each fixed finite Taylor coefficient. The origin/endpoint theorem alone is not an infinity expansion theorem. For this narrow class the exact soft-factor translation/ordinary-zero proof supplies the new algebraic ingredient; the existing region owner supplies the expansion. Bind that use explicitly, and fail if its enumerator or hard/soft projection cannot represent a generated term. No evidence here justifies an arbitrary retained rational soft factor, arbitrary virtual rank, or an incomplete branch enumeration.

## Engineering gates versus theorem scope

The finite-eta origin, uniform endpoint, thermal order and projector bridge have concrete reviewed arguments for the retained h<=2 class. No additional analytic bubble/sunset value is needed. Their missing live bindings are engineering gates: cancellation/context threading; bounded complete support/chart reconstruction; raw guard handoff; generated-label coverage; identity propagation; and the actual Frobenius/combined-target consumer.

Internal CAS scratch is not bounded by the prototype's adapter-event/monomial caps. Before promotion, preflight input text/rational sizes, loops, supports, chart counts, expression degree/term envelopes and checked arithmetic; add cancellation before each potentially expensive native/CAS call and after it. Report these as input/retained-data bounds rather than a total CAS-memory guarantee. If a hard wall guarantee is required, it needs an isolated worker/deadline mechanism; a misleading operation counter is not a substitute.

The narrow region-to-ordinary factorization and its analytic continuation must still be documented in the live boundary token. Actual boundary conversion/evaluation and numerical matching are unperformed integration gates. A failed native closure remains an incomplete reduction, and a failed period/condition/matching check remains an error. There is no demonstrated full-three-loop partial numerical result yet.
