This is an isolated, uncompiled implementation draft. No production source, shared build, native ordering, source equation, work limit or numerical result is changed. The reviewed verified-program reuse integration remains a separate frozen build; this draft preserves its verified internal calls and mandatory final complete replay.

`WeightedClosureOptions.max_history_candidate_maps: Option<usize>` is accepted only for active-target closure. `None` preserves the existing complete ordered history loop. `Some(n)` attempts at most the first n stored-index lexicographic historical labels after the complete final replay, every original weighted target and every basis derivative have passed. `Some(0)` omits optional individual maps. This bounds optional label count, not native applications within a label or wall time.

Mandatory algorithms, target order, derivative order, resulting matrix, terminal set and native application budgets are unchanged. All conditions collected before optional work remain in the same map. Conditions from every executed optional application are also retained, including individually unresolved applications. Skipped work creates neither values nor guards. `retired_unresolved` counts only assessed unresolved labels; selected, assessed, certified-map and unassessed counts are separate. The closed checkpoint includes exact selected and unassessed lists and explicitly denies that historical membership or unassessed status is a coverage/zero/unresolved certificate. No closed checkpoint precedes the mandatory audits.

Existing `Progress::Stage` events expose entry to final complete replay, original-target audit, basis-derivative audit, optional history collection and final checkpoint publication. They are observational phase markers, not completion or timing claims. Cancellation before final replay is explicitly checked. Existing cancellation/native errors from performed work remain errors; no exception is swallowed.

The runtime validation harness gains an optional `RUSTFLOW_WEIGHTED_MAX_HISTORY_CANDIDATE_MAPS` setting. Absence means None. The ordinary/inactive path rejects an explicit value, including zero. Configuration/debug metadata, saved closure checkpoint metadata and JSON diagnostics expose the choice and coverage. No cache schema or ordinary physical-family/refinement behavior is changed by this draft.

Five focused tests are drafted: complete versus zero/one/unbounded limits preserve the required connection and exact native bytes; inactive configuration rejection; mandatory work failure remains failure with zero optional maps; cancellation before final replay; and a cancelled weighted target keeps its required symbolic guard while individually uncovered summands remain explicitly unassessed rather than manufactured maps. The prior default retirement regression remains unchanged. These tests have only been formatted, not compiled or run.

The semantic consumer audit is separately frozen in `../2026-10-10-historical-candidate-collection-assessment/`. Actual parent profiling currently stalls inside a required next-needed native reduction before any optional history sample. This draft is not evidence of a fix for that delay. Before promotion, compile/test in a separate coherent source batch after the verified-reuse baseline; compare actual connections and full inherited conditions, and report phase costs rather than attributing all final work to candidates.
