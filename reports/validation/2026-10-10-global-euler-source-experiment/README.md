The sixteen selected labels are the first four lexicographic later-frontier labels in each of four disjoint strata: C1/bulk, raised-cut/bulk, C1/surface and raised-cut/surface. The copied completed round003 native program is fully decoded and replayed solely to verify every selected label is actually NoApplicableRule. Its rules are then discarded. Every generated per-point program is encoded, decoded and applied again, preserving coefficients and conditions. No custom elimination or numerical integral is used.

The result is negative: all sixteen application maps and condition lists coincide exactly, with 140 RHS terms in each arm. Both arms apply all sixteen labels. Wall times were 18.76 and 18.89 seconds; peak child RSS was approximately 60 MiB. These are bounded diagnostic observations, not proof that the redundant presentation can never help another target. No full pilot or production promotion is justified by this sample.
