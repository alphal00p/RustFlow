# Normalized global boost: reciprocal-domain attribution

The widened normalized boost initially improves the 19 physical probe reductions from 192 to 143 RHS terms. A subsequent polynomial-only control reproduces all 19 RHS coefficient and condition maps exactly, with 143 terms and no positive compact-energy admission. Therefore this finite experiment provides no reason to widen production admission. The row-level comparison and independently derived raw-shell Ward source explain the gain as source presentation.

Six small controls use the same original 19 labels plus two explicit E0^-1/E0^-2 auxiliary probes:

The two normalized orders agree exactly. Widening alone changes none of the original 19 maps. All native programs encode/decode and replay; original polynomial controls leave both positive-E probes explicitly uncovered, while widened controls obtain native recurrences for them. Some source additions also worsen one existing one-term row to eight terms, so shorter aggregate counts are not a monotonic per-label improvement guarantee. No full active-closure pilot or numerical evaluation was run here.

The polynomial arm retains a6<=−1. Widened arms use only exact E0 in slot 6 of future occupied loop 0, mass 0, mu 1; all other completion, occupation and storage-tail bounds remain. Existing lower-contact and free-virtual zero boxes extend only this axis under the separately bound finite-label high-D radial continuation from the reciprocal-energy assessment; no new zero boxes are invented. This is an exploratory source context, not a production permit.
