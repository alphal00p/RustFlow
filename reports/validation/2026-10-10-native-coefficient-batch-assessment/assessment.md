The next candidate is exact grouping of identical denominators inside a bounded pending-label buffer. This is an unimplemented measurement proposal, not a production recommendation. The preceding balanced-tree experiment preserved the exact result but reduced the separately measured wall time only from 313.801 to 303.354 seconds, which did not establish a material improvement.

The actual pinned Symbolica implementation of RationalPolynomial addition first unifies differing variable maps. When denominators are equal, it adds the numerator polynomials and calls from_num_den(..., true). For IntegerRing, that constructor computes a numerator/denominator GCD and canonicalizes the sign. Thus even the equal-denominator fast path repeats a polynomial normalization after every pair. The unequal-denominator path already computes a denominator GCD, forms reduced cross-products, and cancels against that GCD; replacing it speculatively with denominator products or a generic LCM is not justified.

For a buffer with at most 32 terms and one exact coefficient ring/variable map, partition by exact denominator equality. A linear scan is sufficient for this small bound and avoids introducing a new hash-equivalence contract. Sum each group's polynomial numerators in a deterministic balanced tree, then construct one fully canonical rational coefficient with from_num_den(..., true). Drop exact zero groups. Combine distinct groups using the unchanged rational Add owner. Single-member groups need no reconstruction. Do not use from_num_den(..., false): summed numerators can acquire a common factor even when every incoming fraction was canonical.

This changes no equation, coefficient value, source, rule selection, condition, or integral domain. Canonicalization still happens before a popped label is inspected and before pending-capacity compaction or WorkLimit output. The already-reviewed capacity and failure behavior of the bounded buffer must remain byte-for-byte equivalent in control results. Applied-rule guards remain separate from the internal coefficient simplification. The normalizer is the existing Symbolica owner; arithmetic or native errors must remain fatal or propagate as Result, never become zero or NoApplicableRule.
