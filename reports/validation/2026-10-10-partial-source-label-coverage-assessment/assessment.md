# Partial-continuation label coverage: ownership recommendation

The universal finite-label theorem plus a proved invariant of the emitted source rows is sufficient to license a finite native proof and reduction. A separate recorded dimension witness for every intermediate node is not mathematically necessary. The old prototype's statement that consumers audit every individual application label is stronger reporting than this theorem needs; it should be replaced by an explicit distinction between universal source-class coverage and enumerated physical-consumer audits. No native hot-path observer, larger proof format, alternative reducer, or production source change is recommended solely to meet that old reporting promise.

This is a read-only assessment. It adds no source checker or admission. The partial proof and boundary/endpoint owners remain separate; an unchanged final numerical audit cannot by itself establish a new partial placement.

## Admitted class and source invariant

For the bound physical family and exact partial placement, define A by completion indices <=0, every occupation index >=0 and every storage tail fixed at zero. Ordinary physical powers are arbitrary finite integers. Required-cut indices <=0 are allowed as exact cut-zero labels only **after** all the other role, completion and tail checks; they do not excuse an invalid distribution tuple. The origin capability must have already checked the complete physical inventory, all positive virtual supports, the exact common translation and native/channel/chart proof. Every explicit zero box must be a subset of A and carry its separate origin or virtual-zero justification.

For each original emitted source, retain its exact base guard G, coefficient/index map, row, nonzero conditions and identity. The needed invariant is:

```
for every integer a in G on the retained nonzero-condition locus,
  every row image L_t(a) with coefficient c_t(a) != 0 belongs to A.
```

This is not plain interval inclusion of G+shift in A. For example, a completion derivative has image a_E+1 on a_E<=0 and coefficient -a_E: the formally positive image occurs only at a_E=0, where its coefficient is exactly zero. The shifted whole-U presentation has base a_E<=-1, image a_E+2 and coefficient -(a_E+1); its only offending face likewise vanishes. Requiring the raw image box itself to be admitted would incorrectly reject these valid polynomial identities. Conversely, assuming a boundary coefficient vanishes without checking its exact specialization would silently admit an inverse completion.

The current physical generator supports the invariant structurally. Its numerator basis contains no occupation slots and converts polynomials to nonpositive shifts. Ordinary/cut differentiation supplies the raising factor -a_i; an occupation derivative uses the explicit H0 branch or -H for positive H and only raises that occupation index. Multiplication lowers H only on its H>=2 branch; H1 has its separate annihilator row. Whole-source reindexing intersects the original polynomial guard before pulling it back and shifts every coefficient, condition and row label together. Storage shifts are checked zero. Raw singleton Ward sources require their independent singleton-germ permit and are omitted for the partial bundle. These mechanisms justify a reusable exact check on the **actual emitted rows**, before discovery, rather than a graph-specific exception.

## Minimal private checker

Prefer a RustFlow source-owner helper, invoked after lowering/condition preservation and before handing the context to discovery:

```
certify_source_image_class(context, admitted_domain, physical_binding,
                          source_image_budget, run_context)
    -> SourceImageClassCertificate
```

The certificate should have private fields and immutable report/accessors. Bind the exact family/placement/origin identity, physical/storage arities, native source identity and ordered rows/guards/conditions, coefficient/index maps, admitted domain and checker version. Record numbers of rows, terms and exact boundary specializations checked; do not call this a list of every executed intermediate. The partial bundle may retain this certificate identity.

No new native getter is needed: GuardedContext exposes sources(), GuardedSourceSystem exposes native_sources(), sources(), roles() and zero_domains(), and SourceSystem exposes rows(), index_variables() and fixed(). The production physical lowering emits symbolic same-axis row displacements. A checker can conservatively reject an unsupported non-factory pattern. If it accepts native fixed coordinates too, it must use their absolute replacement semantics, not add a displacement to a fixed value.

For each source, first require G subset A. Combine duplicate identical row images exactly, preserving the already collected original poles. For each coordinate of each remaining image, form the part of G violating the corresponding A bound. Empty violations need no work. On each finite violating integer face, specialize that coordinate and every other fixed coordinate in the exact cleared polynomial coefficient and require identically zero in all remaining indices and parameters. Multiple-coordinate violations are handled by checking each coordinate's violating set; there is no need to enumerate their Cartesian product. If a violating set is unbounded or exceeds the explicit face budget, return an unsupported/limit result unless the coefficient is already identically zero. A valid coefficient may have conditions excluding a bad face, but the first implementation can reject that case conservatively instead of adding a logical condition solver. Never erase raw nonzero conditions while proving a coefficient zero.

This check must precede every cut/measure-zero projection. Native guarded roles validate occupations, but know neither the physical completion interval nor the entire occupied-family admission theorem. In particular, ordinary instantiation can remove a missing-required-cut column before later role-image checks. A source-level check of A closes that reporting/ownership gap without changing native semantics.

## Why native closure preserves it

1. GuardedSearchScope checks that the entire source-seed image lies in the original source guard. Same-axis symbolic coordinates are translated; numeric seed coordinates are replacements. Exact zero coefficients are removed by native instantiation/coalescing.
2. At each fixed integer specialization on the retained condition locus, every nonzero resulting source column therefore lies in A by the invariant. A symbolic image box may still include a forbidden boundary where that column coefficient specializes to zero. Native elimination only takes linear combinations of those columns. It does not invent a physical integral label. Explicit measure zeros remove only uniformly covered images of the recorded discovery domain.
3. Exact replay repeats instantiation and multiply-back. Recentring intersects the discovery domain with its translated pullback and every original source guard's seed preimage. Thus a saved rule cannot extend its proof to a different unlicensed source face. Fixed coordinates retain absolute semantics.
Replay retains the normalized source-weight denominators and pivot conditions as well as original source poles. Dividing a boundary-vanishing coefficient by its index factor therefore cannot activate a forbidden label at that factor's zero: the resulting rule is conditional there, rather than an unconditional cancellation. These guards are essential to the induction.

4. Concrete apply specializes coefficients and conditions, skips exact zero RHS coefficients, checks descent, and emits only columns of that replayed identity. Its removed zero children are also covered by the source invariant and bound zero-domain proof. Required-cut zeros are justified within A, not used to broaden A.
5. Starting from admitted originals and derivative inputs, induction covers every nonzero pending/intermediate/terminal/unresolved label. Work limits, missing coverage, vanishing guards and unsupported powers remain explicit; none grants a zero or a master.

Direct-zero discovery uses the same guarded instantiate/seal/replay owner, so it has the same coverage. Verified rule union only combines previously replayed immutable rules in one exact context and common order. The new optional unit memo reuses complete reductions within that same context; its narrowly replayed terminal promotion adds only old NoRule labels. Neither mechanism changes source-class coverage. A cache hit need not recreate a diagnostic application trace that was never part of the mathematical certificate.

The finite proof at a fixed integer input uses finitely many finite-index identities. The reviewed continuation schema supplies a sufficiently high-D open neighborhood for their finite degrees and jets; a common neighborhood is obtained by taking sufficiently large bounds and avoiding their finite coefficient-pole loci. Exact meromorphic continuation then licenses the identity. This does **not** assert one dimension for every point of an unbounded symbolic ray. Failed or discarded discovery rows need no new physical conclusion, but are still instances of the same universally certified source class.

## Explicit physical-consumer audits remain

Audit the original physical target labels and raw coefficient conditions before cancellation/zero classification; the final basis; every actual raw eta-derivative input/output of the final basis; reconstructed target support; retained candidate keys and support; and all region/boundary distributions actually consumed. Preserve exact coefficient conditions and the complete rational target projection. The current flow audit includes original/final basis/target/candidate labels but does not explicitly include the raw final derivative labels; add that finite set to the partial integration's consumer audit. Endpoint continuity concerns the full original weighted target, not an independently projected limit of each master. Boundary region labels have their own distribution/affine-translation validation and cannot be inferred from native index coverage alone.

The explicit report should separately name (a) universal source-class theorem and exact source-image certificate, (b) enumerated physical-consumer label audits, and (c) final native source replay and target/derivative reconstruction. Do not claim a complete applied-label trace, or identify an enumerated final set with such a trace.

## Budgets and optional finite envelopes

Bound source rows, aggregate terms, coefficient polynomial terms/degree/encoded input size, violating-face specializations and checked integer arithmetic before the checker runs. Check cancellation before/after each CAS specialization and between source rows. These bounds describe adapter inputs and retained evidence; they do not bound CAS scratch or its internal arithmetic. Source and rule conditions remain owned by existing exact coefficient handling.

Native application limits bound applied-rule counts and pending integral counts, while discovery has depth/domain budgets and direct-zero has an attempt budget. Depth/domain budgets alone do not equal a measured row/operation limit. Retained-rule caps do not cover every discarded search row. Do not retrofit those names into a claimed exhaustive finite-index report.

If a future consumer really needs a concrete per-run envelope, it is optional evidence and should be implemented separately. A same-axis affine rule gives a checked bound from initial/fixed label extrema plus application_cap times the largest absolute RHS-minus-LHS displacement; also include raw source-seed images before and after recentering. Final rules alone cannot bound every discarded search seed. Native Power currently stores -64..63 offsets or fixed values, and successful numeric applications require that compact representation, but symbolic bases are unbounded and terminal/zero short paths can accept larger i64 labels. Therefore the packed Power range is neither an unbounded-domain high-D witness nor a substitute for an explicit input/proof envelope. Overflow or exhausted audit budgets must stop the audit, not weaken its class.

## Meaningful required tests

- Accept -a_E I(a_E+1) at a_E<=0, and the shifted -(a_E+1) I(a_E+2) at a_E<=-1; reject the same offending images with constant nonzero coefficient. Exercise two-step boundary faces and a coefficient with retained parameter poles.
- Reject negative H images and nonzero tails even when another required cut is absent. Accept a valid cut<=0 zero only after the full tuple check.
- Exercise every emitted source family and both double partial placements; check all zero boxes against A. Partial evidence must not add singleton Ward authority or inverse completion admission.
- Numeric/fixed seed, symbolic seed, target recentering and explicit-zero projection controls must preserve the original guard. Include a recentering face which is outside the original source guard.
- An original-to-intermediate-to-final chain whose final output is valid but intermediate completion is invalid must be rejected at source certification; a final-output-only audit is insufficient. Conversely, a boundary-zero coefficient must not create a fictitious invalid intermediate.
- Wrong family/placement/options/source rows, changed conditions, cancellation, counter overflow and row/term/face-budget exhaustion reject before returning a certificate.

No new runtime feature is justified by this assessment alone. The private source-image checker and expanded finite consumer set are the smallest concrete integration obligations if the partial proof owner is promoted; the native reduction API can remain unchanged.
