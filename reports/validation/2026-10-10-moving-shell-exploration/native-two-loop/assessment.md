# Moving-shell sunset: bounded native closure assessment

The proposed weighted measure can be constructed and differentiated through the
existing public algebra APIs, without changing production RustFlow. These six
bounded experiments do **not** establish an advantage in native closure: every
arm remains explicitly unresolved. No boundary constant or amplitude was
evaluated, and no reference or oracle value entered this experiment.

The physical fixture is `examples/finite_density/massive_two_loop_sunset.json`,
with both its scalar target and its raised original `g1_2+u1*u2` target. The two
cuts examined are the mixed `[0]` and fully occupied `[0,1]` sectors. Each uses
the same Lorentz/multiplication source generator and bounded native discovery.

| Sector | Cut shell / occupation | Frontier after each round | End state |
|---|---|---|---|
| Mixed | Fixed / energy | 22, 48, 68, 80, 92, 104 | 6-round limit |
| Mixed | Fixed / spatial + Gamma | 37, 85, 137 | 128-frontier limit |
| Mixed | Moving / spatial + Gamma | 59, 164 | 128-frontier limit |
| Double | Fixed / energy | 16, 48, 133 | 128-frontier limit |
| Double | Fixed / spatial + Gamma | 30, 80, 190 | 128-frontier limit |
| Double | Moving / spatial + Gamma | 47, 173 | 128-frontier limit |

The source rows, candidate search domains and retained rules are exact native
objects. The prototype retains nonzero conditions and discovery gaps, rejects
non-NoApplicableRule application failures, and would require a replayed final
target/derivative audit before reporting closure. None reached that final stage.
The 128-label budget is checked after each finite round, so the final reported
frontier may overshoot it; it is not an allocator cap. Resource logs and library,
executable, fixture and probe-source hashes accompany `summary.json`.

This deliberately small driver keeps a monotonic provisional frontier. It does
not use production active-target rebuilding, guard refinement, normal-source
policies or direct-zero discovery. In particular, its failure to close the
existing fixed-shell control does not contradict the successful production
massive-sunset implementation. These counts compare the chosen source/search
presentation, not minimal master counts or intrinsic complexity.

The moving measure has physical factors `D_i-eta`, including cut factors, and
fixed spatial upper occupation `mu_i^2-m_i^2-q_i0^2+q_i^2`. Its eta derivative
raises every flowing physical index with coefficient `+n_i`. The occupation
indices do not differentiate because their factors are eta independent off
shell. For each occupied index n, the physical raised target uses

`Gamma_n = C_n H_0 - sum_(j=1)^(n-1) C_(n-j) H_j / j`.

The fixed-spatial control uses exactly this expansion while keeping cut shells
fixed; it is distributionally equal to the fixed-energy control at every eta.
Both controls shift only uncut physical factors. The moving arm shifts all
physical factors. All arms keep the original converted target coefficients
fixed. Thus their physical endpoint is preserved; the moving arm does not claim
that the original polynomial numerator stays fixed along the entire path.

The positive-shell lower-contact zero domains remain valid: the shell mass
squared is 1/4 in fixed controls and 1/4+eta in the moving arm, with eta>0.
An exploratory source-identity prose field uses the latter expression
generically; the serialized factor list records the exact expression for each
arm. Only strict positivity is used for this zero proof. These exploratory
identities are not production cache/admission objects.

The API work needed for a production comparison is concrete: an additive
deformation owner admitting cut shifts, role-aware derivative construction,
fixed-spatial occupation and Gamma target support, and use of the existing full
closure policy with that derivative owner. `FixedShellDeformation` intentionally
rejects shifted cuts and has not been weakened. Keeping the original numerator
polynomial fixed instead would additionally need exact eta-dependent target
rebasing and its coefficient derivatives.

The boundary issue remains independent of closure. The mixed moving-shell
sunset approaches a hard massive two-point integral with external invariant 1,
not an ordinary vacuum seed. The saved mathematical assessment proves the
positive-real/right-half-plane gap for this small sunset and identifies that
additional boundary owner. It does not provide a generic moving-shell contour
or hard-boundary certificate. The current evidence therefore supports further
controlled investigation, not switching the production strategy on the strength
of these probes.
