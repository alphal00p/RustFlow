# Ordinary AMF child for the moving-shell hard boundary

The existing ordinary RustFlow owner evaluates the leading mixed-sunset hard bubble with unit squared masses and external Minkowski invariant `p²=1`. This is an isolated child feasibility test, not a full moving-shell sunset evaluation or an integrated boundary adapter. No production files were changed.

The standalone probe calls `PreparedFlow::new` and `PreparedFlow::evaluate`, with `RustRedBackend { bubble_subloops: false, max_depth: 3, ... }`, both physical lines shifted, and `RecursiveTerminalPolicy::TadpolesOnly`. Its large auxiliary-mass boundary uses the native one-loop massive-vacuum/Gaussian coefficients. No analytic bubble expression, endpoint reference, fitted coefficient or custom terminal is supplied. Exact native preparation closes a three-integral basis; `result/system.json` retains the basis, connection, targets and conditions.

The native measure is `d^D k/(i pi^(D/2))` and the two denominators are `k²-1+i0` and `(k-p)²-1+i0`. Wick rotation supplies two propagator minus signs, hence a positive overall phase. Consequently at `D=12/5` the native value equals `(4 pi)^(6/5)` times the independently saved hard coefficient in `../radial-reference.json`, whose virtual measure includes `(2 pi)^(-D)`. The Feynman polynomial `1-x(1-x)>=3/4` fixes the below-threshold real branch. The comparator performs this measure conversion only after every native prediction is saved.

All three profiles `(digits, guard_digits, Taylor order) = (20,40,60), (30,40,60), (30,40,80)` pass their independent reference checks; two precision/order comparisons also pass. The relative and imaginary-absolute criteria are `1e-18` for the 20-digit profile and `1e-28` for the 30-digit profiles. The largest observed relative reference difference is `8.70e-57`. These are empirical checks against saved high-precision quadrature, not a rigorous integration-error bound. Native execution took `0.57685 s`, peak child RSS `18432 KiB`; compilation and Nix startup are excluded and this shared-host timing is not an isolated benchmark.

`build-binding.json` records the exact standalone source and existing library hashes and the canonical production snapshot. `resources.provenance.json` records the executable hash before execution. `result/predictions.json` and each profile were written before `comparison.json`; the latter binds its saved inputs and source by SHA256. The first comparator launch used a Python environment without mpmath; adding the same mpmath module path used for the independent quadrature resolved this tooling issue without changing any predictions or numerical algorithm.

Remaining work is the generic moving-shell boundary adapter: derive its hard child kinematics, spatial-moment prefactors and higher coefficients, invoke ordinary AMF children, and retain branch/region and raised-surface evidence. This test does not establish complete moving-shell closure or any three-/four-loop finite-density acceptance.
