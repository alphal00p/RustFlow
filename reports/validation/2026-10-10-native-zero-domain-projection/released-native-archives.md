The completed `zero-projection-two-loop-fixed`, `zero-projection-two-loop-priority-fixed`, and `priority-three-loop-fixed` native checkpoint payloads and raw process logs are stored losslessly in `.gz` files. Inputs, configuration, failures, small metadata, resource summaries, and bindings remain plain. The current guard-point build and condition diagnostic are untouched.

`released-native-archives.json` maps each original path to its deterministic gzip path and records both hashes and byte counts. The original `pre-refinement-artifacts.json` has not changed. Run `python verify-released-archives.py` from any directory to verify all compressed payloads and all 311 frozen file/external hashes, resolving missing raw paths through the archive mapping. The successful verification is recorded in `released-native-archive-verification.json`.

Historical probe commands still name their original raw inputs. To restore an input exactly, run `gzip -dc ARCHIVE_PATH > ORIGINAL_PATH` using the manifest entry, then rerun the verifier. Do not restore or overwrite a path owned by a running producer. No numerical value or closure claim changes as a result of this storage conversion.
