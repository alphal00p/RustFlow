This is a read-only design audit, not an implemented admission extension. The existing all-uncut production path and its evidence remain unchanged. No numerical values, oracle answers, new rules, or period formulas are used here.

The current public API is fail-closed. `MasslessFlowEvidence::new` calls `massless_channel_evidence` at `src/finite_density/massless_endpoint.rs:1734`, before constructing a class. The latter requires the supplied shifted vector to equal the complete ascending uncut physical inventory (`massless_contour.rs:107–117`). Every proper subset, duplicate, added cut/completion slot, and different order is rejected. Evidence fields are private, and the type has no public unchecked or deserialization constructor. Consumers recheck the bound family and shifted vector. Therefore the shifted-as-complete-row uses below are currently protected assumptions, not an admitted partial-mask bug. A direct constructor rejection regression is nevertheless useful before refactoring this guard.

The proposed structural test can be generic without graph names. Start with all actual uncut physical rows in occupied/virtual coordinates, `p_e=A_e k+C_e q`; cut coordinates and their distributions remain fixed. For a proposed shifted set M, solve exactly for a virtual translation `k=k'+T q` such that `C'_e=C_e+A_e T=0` for every unshifted physical row. Require every nonzero purely compact physical row to be shifted. The block triangular translation has determinant one; retain its exact matrix and verify every original quadratic and the family routing/target identity. This is an algebraic routing witness, not by itself permission to reset a complex integration contour. Derive it in the ordinary Euclidean/regulated analytic family and retain the common continuation when using complex shell energies.

For the tested singleton, q=P1-P3, t=P3, l=P2 makes slots 0,2,1,4 equal t+q,t,l,l-t; M={0} meets the criterion. For the tested double, q=P1, r=P1-P3, p=q-r and k=P2 give slots 1,4,2 equal k,k-p,p. M={2,4} meets it directly. M={1,2} uses k'=k-p. Rejecting that second mask from the canonical coordinates alone would miss a valid placement. Conversely, existence of a favorable translation does not certify arbitrary contours or endpoint limits.

On any full-rank positive virtual support, with positive Schwinger parameters, let A=sum(alpha a a^T), B=sum(alpha a c^T), C=sum(alpha c c^T), and Q=C-B^T A^-1 B. The exact Gram identity gives 0<=Q<=C. Since every unshifted row has c=0, C sums only shifted virtual rows, hence C<=K*S*I for a retained exact finite rational bound K, with S=sum of the positive shifted VIRTUAL parameters. Thus each external coefficient Q_ij/S is uniformly bounded in the positive parameter interior. This is a matrix statement before contraction with Minkowski compact momenta; it alone does not prove the physical Feynman channel has nonnegative real part. A separate channel/common-regulator proof remains necessary. Pure compact transfer factors are outside the virtual Gaussian inventory and need their own shifted gap and jet bounds.

Classify every actual positive virtual support before applying that inequality:

- Rank deficient: retain an exact virtual null vector. Only finite polynomial numerators depend on the unconstrained direction, so its ordinary dimensional integral is zero. Never count compact rows as virtual rank.
- Full rank with no positive shifted VIRTUAL row: after the recorded translation all positive virtual denominators are homogeneous massless quadratics independent of compact momenta. Separate the ordinary vacuum tensor integral from compact coefficients. The scaleless prescription and uniform removal of independent line regulators require a proof for that support; no finite regulator value is declared zero. A shifted pure compact transfer may still be present and does not give the virtual vacuum a mass.
- Full rank with positive shifted virtual support: construct the U, S and complete external/mass coefficient polynomials from all active physical rows. V=0 alone is not a zero certificate; a shifted tadpole is a nonzero finite-eta massive germ.

Nonpositive physical indices and nonpositive completion indices are expanded as finite polynomials before support classification. Do not analytically continue through deleted Schwinger factors. Any zero box must intersect the complete actual admitted domain, including positive required cuts, valid occupations and zero storage tails.

The Schur bound is not yet a generic smooth-germ certificate. Bounded rational functions can have non-smooth derivatives at corners. For example xy/(x+y)^2 is bounded on the positive quadrant but has no unique limit at its origin. Uniform parameter-face continuation requires more than an interior bound. The explicit small-family proof supplies complete monomial charts with U and S equal to monomials times positive analytic units and with every relevant external coefficient divided by U*S having nonnegative monomial valuations and a smooth bounded unit. It also supplies finite Taylor subtraction with uniform regulator and mass/energy-jet estimates. Extending that evidence to general routing needs a bounded complete resolution and exact replay, or a separately established general theorem supplying the same uniform continuation. A failed budget or an unresolved chart is Unsupported, never an omitted support.

The saved small support proof covers 16 singleton and 4+4 double supports, with 46 and 3+3 germ charts, and explicitly controls the independent line-regulator zero limit for its one-/two-loop vacuum supports. That does not establish the analogous arbitrary-rank vacuum UV/IR continuation. Keep the existing high-D finite-jet interpretation: a proof neighborhood may depend on each finite label, and there is no one finite D for an unbounded family. Retain fixed positive eta/T, common same-sign independent line regulators, the Fermi pole strip, regulator removal before the T limit, and joint meromorphic continuation. Higher occupation derivatives must be handled in the established complete thermal construction. A new reciprocal energy completion or pole is outside this proposal.

The minimal ownership separation is three bound capabilities, with shared immutable routing/placement data:

1. `OccupiedPhysicalRows` (name illustrative) owns every actual uncut physical row, all virtual/compact coefficients, the exact translation, physical/completion partition, and full family/target identity. It owns support rank and polynomial insertions. `AuxiliaryPlacement` owns only the shifted physical slots and unit mass coefficients, plus virtual versus pure-compact membership. The current all-uncut constructor can keep its identity unchanged when both inventories coincide.
2. A sealed finite-positive-eta `MasslessOriginEvidence` owns the support-complete germ/vacuum/null-direction proof and the specific lower-origin/virtual-zero boxes. It may authorize the source factory and separately justified raw polynomial Ward sources. It must not authorize eta-zero projection or infinity constants. Existing `MasslessFlowEvidence` can expose an origin view for compatibility; a partial-origin proof must not impersonate an existing endpoint class.
3. Separate endpoint and infinity-boundary evidence own their corresponding operations. The endpoint proof must address eta->0 after the complete common continuation and every retained label; changing the location of the mass does not justify dropping nonanalytic eta branches. The boundary proof must inspect every generated region and projected product. It may remove a rational soft factor only after exact factorization into an ordinary homogeneous massless virtual integral independent of compact momenta. Polynomial compact factors remain integrated, and the all-hard child remains the existing ordinary AMF/RecursiveBoundary owner with shortcuts disabled.

A counterfactual regression demonstrates why the current public equality gate must remain until these changes are complete. Use the three-loop chain, singleton cut[3], routing (q,t,l) above, and hypothetical shifted M={0,1}. The shifted virtual rows t+q and l span two dimensions, but the complete inventory also includes unshifted t and l-t. A helper using only shifted rows would label slot0<=0 as a free t direction. At physical powers [0,1,1,1,1], however, the virtual factor is the two-loop vacuum with denominators l^2+eta, t^2, (l-t)^2. It is nonzero: its Euclidean scalar integral is positive and convergent in 2<D<3. The compact shell contributes a separate nonzero moment. This is not reachable through today's public constructor; it is a required negative test for a future relaxation. It also prevents treating all V=0 supports as zero.

Before production admission, tests should cover: current public partial-mask rejection; exact complete-row inventory; equivalent virtual translations for both double masks; a failed translation and an unshifted pure transfer; complete support classification including nonzero shifted tadpoles and the counterfactual one-mass vacuum; tampered row/shift/target/determinant/support evidence; all chart and support budgets failing closed; high-order finite jets; original numerator held fixed before specialization; and exact cache/serialization distinction for every placement/proof version. Generated source rows and native proofs must be compared independently, and full boundary/transport predictions saved before reference comparison.

Cache/provenance identities must include the input and complete physical family, cut orientation and chemical assignments, the actual shifted set and coefficients, the affine witness, full support classification and proof version/digest, admitted lower/virtual-zero domains, source options, and separate endpoint/boundary versions. Reusing an old all-mass source program or cache entry under a partial mask is forbidden. Symbolic eta/epsilon guards and original target coefficients remain unchanged, and native final complete replay stays required. None of this design establishes three- or four-loop numerical acceptance.
