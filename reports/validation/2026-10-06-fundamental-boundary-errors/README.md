# Signed propagation of supplied boundary errors

This milestone adds an opt-in `fundamental_matrix` verification policy to ordinary rational physical transport. It propagates a signed global fundamental-matrix candidate and certifies its inverse, exact-source defect and chart jumps with native Symbolica/Numerica matrix and ball-polynomial operations. A small cumulative Neumann bound then propagates the separately supplied component errors. The existing `scalar_norm` policy remains the default and the fallback when the optional proof is unavailable or inconclusive.

The public Rust, CLI and Python surfaces expose the policy and proof/fallback diagnostics. Cache persistence, compatible-source selection, intermediate-point insertion, cancellation, independent central precision/order refinement and input accuracy caps retain their existing owners. No source precision is inferred from stored digits, and a failed trajectory inserts no points.

The final corrected source passes 75 scoped tests: 7 private proof controls, 62 integrations across 11 binaries, 4 CLI tests and 2 Python/stub tests. Native and Python/stubgen release all-target Clippy with `-D warnings`, and formatting, also pass. `report.json` records the source and dependency digests. `evidence.tar.gz` contains the frozen source, logs, build metadata and a per-file SHA-256 manifest. The prior 72-test snapshot is retained separately: its arithmetic contract was unchanged, but review identified missing retained-endpoint storage in the resource estimate. The final estimate also charges guard and exact-transpose storage, with a precision-dependent adversarial admission test. The first final Python run also exposed a test-only quotation mismatch in a stub assertion; its failed log and original fixture are preserved, and the affected checks were rerun without changing the implementation.

The main scientific controls are:

- Nilpotent matrices with rates 100, 2,500 and 5,800: fixed 30-digit input evidence supports requested 20-digit long transport under the stronger proof while the scalar norm rejects it. Central values agree with the analytic result to 45 digits; binary restart, exact hits and nearby reuse preserve the source cap.
- A genuinely growing exponential mode: strong input evidence succeeds, while insufficient input accuracy is rejected even when the central value of the growing component is zero.
- A noncommuting complex manufactured fundamental matrix, multiple physical charts and a nonzero rounding-jump witness; exact-source refinement at 160, 282 and 400 bits; retained denominator exclusions.
- Actual central Möbius/Padé candidates combined with the independent identity-chart proof; typed cancellation and resource fallback; exact equality between default and explicitly selected scalar handling.

These runtime checks use the unchanged official Symbolica community `c3408e4b` and HEPKit `a3d1c8a8` dependency graph of the isolated worktree. The parent runs a separate integration gate for the requested newer dependency graph. The included `c3408e4b` to `6defcca9` diff audit found no arithmetic-owner or precision API change relevant to this proof; that inspection is not a substitute for the parent's new-pin runtime gate.

This is a bounded first slice: dimension at most 16, order at most 256 and working precision at most 4,096 bits, with further exact-source, coefficient, work and 256 MiB storage estimates. These estimates are not hard allocation or runtime quotas. Multiple epsilon orders, registered roots and unspecialized source maps retain scalar handling. Automatic selection when the scalar bound would reject, sparse hierarchy/root support, and authenticated finite-epsilon transport plus error-aware Laurent fitting remain work to do. No performance or full AMFlow/DiffExp parity claim is made here.
