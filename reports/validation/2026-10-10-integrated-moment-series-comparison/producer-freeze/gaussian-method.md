# Generic Gaussian and compact moment coefficient construction

The implementation reconstructs every target from the actual prepared inverse-propagator indices and coefficients. Physical mass differentiation is already represented by the prepared C/H labels and coefficient conversions, before the selected propagators acquire eta. Neither a graph name nor a selected invariant chooses the integration algorithm. The prototype currently requires massless physical lines, unit routing determinant and original virtual numerator degree at most one. Larger virtual numerator degree must add Gaussian covariance contractions explicitly; it is rejected here.

For every actual positive virtual support, HEPKit constructs the full off-shell Symanzik pair U,F. Independently, the exact routed quadratic matrix A and linear vector B reconstruct U=det(A), the mean -A^-1 B, and the entire F, including compact diagonal terms. The emitted identities are tested before coefficients are produced. The mean suffices for degree-one virtual numerators; after multiplication by U the numerator is polynomial in Schwinger parameters and compact Gram/energy variables.

Expanding the virtual polynomial part of F before virtual integration maps every parameter monomial to an ordinary vacuum integral in a shifted dimension. The generic Gram determinant identity returns this to the original dimension:

    I_(D+2q)[f] = product_(r=0..q-1) { (-2)^h / product_(j=0..h-1)(D+2r-j) }
                  * I_D[(det G_M)^q f].

Its normalization is independently derived and natively tested for one through four loops in the sibling gram-shift report. The present producer supplies these exact ordinary vacuum integrals to RustRed with bubble subloops disabled. It does not evaluate a bubble formula or install a tadpole recurrence. Every emitted hard period remains a separate n-independent master channel. A native result must contain either the target rule or the target among its explicit residuals; missing reconstruction is an error.

All compact polynomials are integrated by a reusable independent-domain functional. For each monomial, the exact normalized distribution identity g_ii^p C_n(g_ii)=C_(n-p)(g_ii), with C_n=0 for n<=0, is applied first. This retains the off-cone contribution for raised cuts. Every remaining off-diagonal Gram factor is expanded as E_i E_j minus its spatial Gram product. The generic angular owner aggregates Wick contraction multiplicities for arbitrary vector graphs, with odd degrees zero. The radial functional then integrates the actual C_n H_upper,s H_lower,l distribution by dimensionally continued binomial moments. Upper surfaces are included; lower-origin jets use the existing common high-D continuation. No compact inverse-energy or unresolved rational denominator is admitted.

The first four integer coefficients of both physical targets agree exactly with the independently executed native region/TensorProjector pipeline, including the ordinary master family. This is a finite correctness check, not an all-order certificate. The angular recurrence has separate exact Cartesian moment tests on three/four independent vectors.

The all-region census enumerates two compact-compatible regions for this input. In the all-soft region every finite Taylor coefficient is polynomial in the unrestricted virtual momentum: all its physical denominators were shifted. The separate ordinary native zero certificate for the empty positive virtual support applies to every such polynomial insertion. The nonzero all-hard virtual region is the one represented by the Gaussian construction. This excludes an omitted soft denominator or second fractional-power branch for this input. The more general all-shift argument extends to a virtual-soft subspace only after its actual region factor is verified to be polynomial; no arbitrary-region assertion is installed in production.

Resource scope is explicit: each exploratory run is capped at 180 seconds, requested coefficients at 64, extracted polynomials at 200,000 monomials, and serialized result payload at 128 MiB. The angular owner independently bounds graph degree and cache entries. These checks do not constitute bounds on transient CAS scratch or all simultaneously retained rational Atom payloads. The successful 24-prefix result is 52,278 bytes and required 48 ordinary hard labels. The first 64 attempt was rejected, without partial predictions, by the unchanged native Power representation at index64 (range -64..63). That failure is preserved. A larger exact native representation or a separately certified symbolic-index application owner is needed; no coefficient is extrapolated across this limit.
