This is an isolated algebra experiment. Production sources, native rules, source conditions, integral order, distribution domains and period values are unchanged.

The capture executable runs the previously checked balanced pending-coefficient driver, retaining at most 32 incoming coefficients per label. Grouping is not used during that reduction. Every nonzero input buffer is classified by exact denominator and coefficient-variable-map equality. The collector retains only the eight eligible buffers with the largest measured baseline balanced addition cost; ties use deterministic invocation order. All eligible/ineligible counts and addition times are reported. Input cloning and group inspection are outside the selected addition-time measurement. At most eight retained buffers plus the current bounded buffer are stored.

The full original 16,937-rule program is decoded and replayed through the native owner before reduction. The seven explicit terminal labels are rebound using the verified immutable API. The saved prior reduction is read only after the independent reduction finishes. Exact output labels, coefficients, ordered conditions, residuals and application counts must all agree before sample publication.

Selected input coefficients and expected exact sums are serialized by the native CoefficientTableBuilder and reimported with full normalization. No expression-only recreation or numerical sampling is used. The coefficient IDs and exact sparse input shapes are saved with the native Symbolica state and coefficient table.

The sample executable compares native sequential rational addition, the unchanged balanced rational tree, and grouping by exactly identical denominators. Each group sums only polynomial numerators, then uses the native Symbolica from_num_den(..., true) constructor once; different groups are combined with unchanged native rational addition. A singleton group is reused unchanged. Inputs with differing variable maps are rejected. All incoming native coefficients are canonical; the constructor preserves canonical signs and cancels newly common factors.

For each sample, three repetitions rotate method order so every method runs first, second and third once. Every result is checked against the exact captured canonical sum. All times and median values are retained; sample results are not extrapolated into a whole-reduction speedup. The capture process has a 600-second wall bound and the sample process a separate 300-second bound. Timeout or arithmetic failure stays explicit.

Eleven standalone tests cover the original seven native/budget controls, including 810 exact native comparisons, plus equal-denominator new-factor cancellation, canonical signs, denominator one/zero, interleaving and buffer boundaries, and variable-map rejection. One initial sample-executable compilation failed because a JSON macro array-index expression needed parentheses. The original source/log remain intact; the corrected source is a separate file, so no hash-bound capture input was modified.
