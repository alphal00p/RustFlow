# Partial occupied-flow wiring: isolated validation

The complete copied RustFlow crate passes production and test metadata checks,
and **50 selected tests pass** with no failures or ignored cases. The selected
harness took 2.73 seconds (2.743 seconds wall,
30,772 KiB peak child RSS). These are shared-host validation
measurements, not a performance comparison. No live source or shared build output
was changed, and no Cargo command was used.

`validation-summary.json` records results and limits. `compile-isolated/r00/`
retains all three successful compile attempts, exact commands, source/dependency
bindings and the selected test list, logs and resources. The executable remains
outside Git at `/tmp/rustflow-partial-flow-full-crate-20261010-r00/test-build-00.bin`. It was compiled as one complete crate
with 21 exact memo-build dependencies; no old RustFlow library was supplied as an
external crate. All 2,632 copied source/fixture/doc assets, 18 overlay files and
dependency/executable hashes passed the recorded post-run checks.

The draft binds an explicit parent placement to a private continuation bundle
for one virtual loop and two occupied massless shells. It preserves complete
assembly's existing placement interface and passes the ordinary All policy to
recursive hard children instead of reusing parent slot numbers. The source-image
certificate binds all emitted rows, guards, conditions, zero boxes and admitted
roles/tails before discovery. It certifies class preservation, not IBP validity.

The independent review found a missing handoff of reduced-expression denominator
conditions. The final source installs those typed conditions in the actual
ReducedSystem before signing and transport; the executed regression checks the
matrix/target/candidate domains and rejects omitted conditions. Boundary tests
also retain raw domains before projection/cancellation, reject missing handoffs,
and exercise both exact virtual-soft zero certificates and nonzero ordinary hard
contributions in actual regions for both supported partial masks. Complete
source replay, weighted reconstruction, finite-label auditing and the existing
symbolic Frobenius/combined-target projection remain mandatory consumers.

The additional tests cover the origin/endpoint proof modules, source-class
checker, placement and contour options, raw poles, mappings, invalid roles and
storage tails, changed identities, cancellation and explicit structural limits.
323 unrelated tests were filtered out. The owner's separate 46-case standalone
result is linked but not added to the 50 unique combined-crate count. The checker
core is byte-identical to its frozen prototype; its two test fixture calls were
adapted separately to the current context API. No standalone private-owner
shims were overlaid into the crate.

This report establishes isolated implementation compatibility and the selected
proof/consumer regressions. **No closed native partial-placement flow or numerical
partial amplitude has yet been produced.** It grants no production admission,
full three-loop or four-loop acceptance, or speed claim. Structural budgets do
not bound internal CAS/encoder scratch or one indivisible native operation.
